* Scope

The owner of the Star-Agent REPL is this repository. Symbolic knowledge
semantics live exclusively in Star-KB; the prolog-rlm provider-native =direct=
runtime is an optional adapter; Star Server and pro-actors own targets and
collection. No competing rule engine or queue is introduced.
